# 🌊 BUSAN VIBES - 외국인을 위한 부산 5대 명소 원페이지 웹사이트

부산을 방문하는 외국인 관광객들에게 가장 인기 있고 반응이 뜨거운 **부산 대표 관광지 5곳**을 선정하여 소개하는 인터랙티브 원페이지(One-page) 웹사이트입니다.

---

## 🌟 선정된 부산 5대 명소 (Top 5 Attractions)

1. **감천문화마을 (Gamcheon Culture Village)**
   - *키워드:* #한국의마추픽추 #어린왕자동상 #골목예술 #인생샷명소
   - *외국인 인기 이유:* 알록달록한 파스텔톤 계단식 주택과 골목마다 펼쳐진 벽화 및 예술작품, 어린 왕자와 사막여우 동상에서 찍는 필수 인증샷.
2. **해운대 해수욕장 & 블루라인파크 (Haeundae Beach & Blueline Park)**
   - *키워드:* #스카이캡슐 #해변열차 #골든샌드 #더베이101
   - *외국인 인기 이유:* 바다 위 공중을 달리는 레트로 감성의 '스카이캡슐'과 한국을 대표하는 현대적 오션 프론트의 만남.
3. **해동용궁사 (Haedong Yonggungsa Temple)**
   - *키워드:* #바다사찰 #기암절벽 #일출명소 #108돌계단
   - *외국인 인기 이유:* 산속 사찰과 차별화된, 거친 동해 파도 바로 앞 절벽에 세워진 신비롭고 영험한 분위기의 바다 사찰.
4. **광안리 해수욕장 & 광안대교 (Gwangalli Beach & Gwangan Bridge)**
   - *키워드:* #광안대교야경 #토요드론라이트쇼 #오션뷰펍 #수제맥주
   - *외국인 인기 이유:* 7.4km 광안대교의 환상적인 LED 야경, 매주 토요일 밤 펼쳐지는 무료 대규모 드론 라이트쇼, 트렌디한 테라스 문화.
5. **자갈치시장 & BIFF 광장 (Jagalchi Fish Market & BIFF Square)**
   - *키워드:* #활어회체험 #씨앗호떡 #오이소보이소사이소 #K스트리트푸드
   - *외국인 인기 이유:* 1층 수조에서 고른 신선한 해산물을 2층에서 바로 맛보는 리얼 미식 체험 및 길 건너 BIFF광장의 씨앗호떡 등 풍성한 길거리 음식.

## 💻 주요 기능 및 인터랙션

- **실시간 한국어 / 영어 전환 (KO / EN Toggle)**: 다국어 지원으로 외국인 친구와 함께 볼 수 있습니다.
- **다크 모드 / 라이트 모드 (Theme Toggle)**: 밤바다 감성의 다크모드와 화사한 라이트모드 지원.
- **테마별 필터링 (Filter Tabs)**: 문화&예술, 오션&액티비티, 야경&핫플, 로컬 미식별 카드 정렬.
- **상세 정보 모달 팝업**: 각 명소별 고해상도 사진, 핵심 하이라이트, 운영시간, 입장료, 대중교통 이용법 및 구글맵/네이버맵 연동.
- **찜하기(Bookmark) 기능**: 마음에 드는 명소를 하트 버튼으로 저장하고 상단 바에서 모아보기.
- **추천 1박 2일 여행 코스 (Curated 2-Day Itinerary)**: 동부 바다 라인과 서부 원도심 라인으로 최적화된 동선 제공.
- **외국인 맞춤 여행 팁 (Survival Kit)**: 네이버지도 앱 필수 안내, 비지트부산패스, 티머니 카드, 24시간 관광통역안내(1330) 안내.
- **인터랙티브 위치 안내 맵**: 부산 지하철 1/2호선과 연계된 5대 명소 위치 핀 클릭 인터랙션.
- **반응형 웹 디자인 (Responsive Design)**: 모바일, 태블릿, PC 등 모든 디바이스에 최적화.

## 🎬 Remotion 모션그래픽 비디오 (Promo Video)

부산 명소 웹사이트를 홍보하기 위한 18초 분량의 모션그래픽 영상이 React + Remotion 기반으로 구성되어 있습니다.

### 📐 제공되는 컴포지션 규격
1. **PromoVideo** (1920x1080, 16:9 가로형 Full HD): 유튜브, 웹사이트 메인 영상용
2. **PromoVideoVertical** (1080x1920, 9:16 세로형): 인스타그램 릴스(Reels), 틱톡(TikTok), 유튜브 쇼츠(Shorts)용

### ⏱️ 타임라인 구성 (총 540 프레임 / 30fps = 18초)
- **00s ~ 03s (0 ~ 90f)**: Intro Scene - 다이내믹 부산 로고 & 파도 모션, 글로벌 트래블러 슬로건
- **03s ~ 12s (90 ~ 360f)**: Top 5 Attractions - 5대 명소별(감천문화마을, 해운대 블루라인파크, 해동용궁사, 광안대교, 자갈치시장) 1.8초씩 다이나믹 카드 쇼케이스
- **12s ~ 15.3s (360 ~ 460f)**: Website Features - 원클릭 한/영 전환, 1박2일 코스, 여행 서바이벌 팁 3대 특급 기능 소개
- **15.3s ~ 18s (460 ~ 540f)**: Outro Scene - 공식 브랜드 로고 및 "지금 바로 부산 여행을 계획해보세요" 방문 유도 CTA

### 🛠️ 실행 및 렌더링 명령어

#### 1. 실시간 미리보기 플레이어 (Remotion Preview Player)
```bash
npm start
```
실행 후 브라우저에서 `http://localhost:3000`으로 접속하면 타임라인 스크러빙, 프레임 단위 재생, 실시간 코드 수정(Hot Reload)을 확인할 수 있습니다.

#### 2. MP4 고화질 비디오 렌더링
```bash
# 가로형 16:9 렌더링 (out/promo-busan.mp4 생성)
npm run build

# 세로형 9:16 (릴스/쇼츠) 렌더링
npx remotion render src/index.ts PromoVideoVertical out/promo-busan-vertical.mp4
```

### 🎵 슬라이드 전환 맞춤 BGM & 효과음 (Beat-Synced Audio)
- **템포**: 100 BPM (명소 카드 전환 주기 1.8초 = 정확히 3비트와 1:1 동기화)
- **전환 스우시(Whoosh)**: 슬라이드가 넘어가기 직전 좌우 스테레오 스윕 효과
- **임팩트 킥 & 차임(Chime Impact)**: 각 명소(감천, 해운대, 용궁사, 광안리, 자갈치)와 씬이 시작되는 정확한 프레임에 타격음 및 반짝이는 코드 멜로디
- **BGM 커스터마이징 및 재합성**:
  ```bash
  npm run generate:bgm
  ```

## ⚡ 버전 2: 하이테크 모션 디자인 쇼릴 (High-Energy Kinetic Showreel)

프롬프트 명세를 100% 충족하는 **미니멀 다크 + 네온 레드 & 화이트 글로우** 테마의 15초(450 프레임) 캔버스 기반 쇼릴 영상입니다.

### 🎨 스타일 & 룩앤필
- **컬러 팔레트**: Deep Black (`#000000`), Vibrant Red (`#FF3300`), Glowing White (`#FFFFFF`)
- **레이어링 & Depth**: 미세 격자 그리드 + 원근 투영 3D 메타볼(Metaballs) 부유 & 에너지 라인 + HUD 테크니컬 오버레이
- **타이포그래피**: Bold 900 Sans-serif 120px 텍스트, 좌측 슬라이드인 스프링 바운스 및 펄스 글로우
- **비트 타임라인**:
  - `0.0s ~ 1.5s`: 다크 스크린 + 레드 수평 레이저 라인 확장 & 텔레메트리 HUD
  - `1.5s ~ 7.5s`: 화이트 플래시 트랜지션 + 그리드 & 3D 메타볼 궤도 공전
  - `7.5s ~ 13.5s`: 2차 화이트 플래시 + 키네틱 와이어프레임 쇼케이스
  - `13.5s ~ 15.0s`: 히어로 텍스트 스프링 슬라이드인 안착 & 펄스 발광

### 🚀 V2 비디오 렌더링 명령어

npm run build:v2

# 부산 에디션 버전 ("BUSAN" 히어로 텍스트)
npm run build:v2:busan
